## 🏫 강의 목표
- **이론과 실무의 결합**: 계량경제학 및 인과추론(Causal Inference) 이론이 실제 정책 평가에 어떻게 적용되는지 Stata와 R을 통해 학습합니다.
- **재현 가능성(Reproducibility)**: 학생들이 스스로 데이터를 만지고 분석 리포트를 코드로 구현할 수 있도록 돕습니다.

## 📂 폴더 구조 및 학습 내용
- `01_stata_basics/`: Stata 데이터 핸들링 및 기초 회귀분석
- `02_causal_inference_stata/`: 패널 데이터, 이중차분법(DID), 성향점수매칭(PSM) 실습
- `03_r_tidyverse/`: R을 활용한 공공 데이터 정제(Tidyverse) 및 시각화(Ggplot2)
- `04_r_advanced/`: R 기반의 정책 효과성 평가 및 회귀진단

## 💻 사용 툴
- **Stata** (버전 16 이상 권장)
- **R** & **RStudio**
