# R-for-Policy-Analysis

# 📊 Stata & R 기반 정책계량분석 및 정책 평가 강의 포트폴리오

안녕하세요! 정책학 박사 나혜선입니다.  
본 저장소는 온라인 강의 환경에 최적화된 **학부 및 대학원 과정의 계량분석 실습 코드와 예제**를 제공하는 오픈소스 아카이브입니다. 

학습자의 배경과 목표에 맞추어 **투트랙(Two-track) 하이브리드 커리큘럼**으로 운영됩니다.

---

## 📘 1. 학부 과정: [데이터 기반 정책 평가 실무] (R 중심)
- **대상**: 행정학/정책학 학부생 및 데이터 분석 비전공자
- **목표**: 수식 위주의 통계학에서 벗어나 오픈소스 R을 활용해 실제 정책 데이터를 다루고 효과를 평가합니다.
- **핵심 실습**: 데이터 정제(`tidyverse`), 시각화(`ggplot2`), 기초 이중차분법(`DID`) 구현
- **[📂 학부 실습 폴더 바로가기](./undergrad_R_course)**

## 📙 2. 대학원 과정: [정책계량분석과 인과추론] (Stata & R 병행)
- **대상**: 석·박사 학위 논문 작성을 목표로 하는 연구자
- **목표**: 인과추론(Causal Inference)의 핵심 방법론을 이해하고, 학계 표준인 Stata와 트렌디한 R을 유기적으로 병행하여 SSCI급 연구 설계 역량을 배양합니다.
- **핵심 실습**: 고정효과(Fixed Effects), 다기간 이중차분법(TWFE DID), 도구변수법(2SLS), 회귀단절모형(RDD)
- **[📂 대학원 실습 폴더 바로가기](./grad_stata_R_course)**
